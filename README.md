# 🧠 Segundo Cérebro aplicado a Investimentos

## 🎯 Contexto e Objetivos

Este caderno temático tem como objetivo a construção de um **segundo cérebro**, ou seja, um sistema externo de organização do conhecimento, aplicado ao estudo de **investimentos financeiros e suas metodologias**. 📎 Acesse a versão oficial [clicando aqui](https://notebooklm.google.com/notebook/8275389e-fe0d-4138-a3ab-93d18d9ff1fc)

A proposta integra:

- Fundamentos de investimentos

### Objetivos de estudo:
- Organizar conteúdos sobre investimentos de forma estruturada
- Facilitar revisão e retenção de conhecimento
- Apoiar a tomada de decisão financeira
- Criar um sistema reutilizável de aprendizado contínuo

---

### 🔁 Variações de Prompts

- Explicações simples vs. técnicas
- Uso de exemplos práticos
- Comparações entre conceitos

#### Exemplos:

- "Explique renda fixa para iniciantes"
- "Compare renda fixa e renda variável"
- "Crie um resumo estruturado sobre investimentos"
- "Como aplicar o método PARA em finanças?"

---

#### 💰 Investimentos

- **Renda Fixa:** previsível, menor risco  
- **Renda Variável:** maior risco, maior retorno  
- **Diversificação:** redução de risco  
- **Perfil de Investidor:** conservador, moderado, agressivo  

---

### 📚 Glossário

- **Renda Fixa:** investimento com retorno previsível  
- **Renda Variável:** retorno incerto  
- **Liquidez:** facilidade de resgate  
- **Diversificação:** reduzir risco distribuindo investimentos  
- **Ativos:** bens financeiros
